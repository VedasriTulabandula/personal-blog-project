# Personal Blog Project

## Overview

This is a full-stack personal blog application.

The project will allow:

* Admin to create, edit, and publish blog posts
* Users to view published posts

## Tech Stack

### Backend

* Java
* Spring Boot

### Frontend

* React

### Database

* PostgreSQL

### Version Control

* Git & GitHub

### Deployment (Planned)

* AWS (RDS + Elastic Beanstalk / App Runner)

## Project Structure

personal-blog-project/
├── backend/     # Spring Boot application
├── frontend/    # React application
